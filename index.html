視線スイッチ（GazeSwitch） / 最終更新日: 2026年9月22日

プライバシーポリシー

日本語 · English

1. はじめに

視線スイッチ（GazeSwitch、以下「本アプリ」）は、iPhone のフロントカメラを使って利用者の瞬きと視線を検出し、Bluetooth リレー基板をオン・オフするためのスイッチアプリです。本ポリシーは、本アプリが取り扱う情報とその扱いを説明します。

2. 顔データ（TrueDepth / ARKit フェイストラッキング）

本アプリは、瞬きと視線を検出する目的に限り、Apple の ARKit フェイストラッキング（ARFaceTrackingConfiguration）を使用します。この機能は、対応端末では TrueDepth カメラを利用します。

2.1 収集する情報

本アプリが TrueDepth / ARKit から利用するのは、次のリアルタイムな数値だけです。

  • 左右の目の閉じ具合（ブレンドシェイプ eyeBlinkLeft / eyeBlinkRight）
  • 顔および左右の目の位置・向き、視線の向き（画面中心からのずれを計算するため）
  • 顔を追跡できているかどうか、およびそのフレームの時刻

顔のメッシュ、顔の写真、動画、深度マップ、顔の特徴量、顔認証用のテンプレート、本人確認に使える生体識別子は取得しません。カメラ映像そのものを保存することもありません。

2.2 利用目的

上記の情報は、利用者が「目を閉じた」「画面を見ている」ことをその場で判定し、スイッチを押したことにしてリレーを操作するためにだけ使います。広告、分析、プロファイリング、本人確認、顔認識、アカウント作成には使いません。

2.3 保存・保持・削除

顔データは端末のメモリ上で、その瞬間の判定に必要な間だけ保持します。次のフレームが届くか、アプリが背面に移るか、フェイストラッキングを停止した時点で破棄されます。ディスク、写真ライブラリ、iCloud、サーバー、ログファイルには保存しません。顔データの保管期間はないため、削除対象の保管データもありません。アプリを削除すれば、端末内に残る顔データはありません。

2.4 共有・開示・第三者提供

顔データは第三者と共有しません。外部サーバーへ送信せず、分析ツール、広告 SDK、クラウドにも送りません。Bluetooth でリレー基板へ送るのは、オンを表す「1」またはオフを表す「0」という 1 文字の操作コマンドだけであり、顔データは含まれません。

2.5 保管場所

顔データは利用者の端末内のメモリ上でのみ処理されます。開発者を含む第三者が管理するサーバーやデータベースには保存されません。

3. その他の情報

3.1 カメラ

フロントカメラは、ARKit が瞬きと視線を検出するためだけに使います。映像は端末内でのみ処理し、保存も送信もしません。カメラの使用は、利用者が許可した場合に限ります。許可は iOS の設定からいつでも取り消せます。

3.2 Bluetooth

本アプリは、利用者が選んだリレー基板に接続し、オン・オフのコマンドを送ります。保存するのは、次回の自動接続のための基板識別子と、利用者自身が変更した設定値だけです。これらは端末の UserDefaults に保存され、顔データではありません。

3.3 ネットワーク

本アプリはネットワーク通信を行いません。アカウント登録、位置情報、トラッキングも行いません。

4. お問い合わせ

本ポリシーまたは顔データの取り扱いについて質問がある場合は、App Store Connect に記載のサポート連絡先までご連絡ください。

Privacy Policy

1. Overview

GazeSwitch (“the App”) detects a user’s blinks and gaze with the iPhone front camera and uses that input to turn a Bluetooth relay board on or off. This policy explains what information the App handles and how that information is used.

2. Face Data (TrueDepth / ARKit Face Tracking)

The App uses Apple’s ARKit face tracking (ARFaceTrackingConfiguration) solely to detect blinks and gaze direction. On supported devices, this feature uses the TrueDepth camera.

2.1 Information used

From TrueDepth / ARKit, the App uses only the following real-time values:

  • How closed each eye is (blend shapes eyeBlinkLeft and eyeBlinkRight)
  • The position and orientation of the face and eyes, and the gaze direction (used only to measure offset from the center of the screen)
  • Whether a face is currently tracked, and the timestamp of that frame

The App does not obtain a face mesh, photographs, video, depth maps, facial feature templates, or any biometric identifier that could be used for identification or authentication. Camera frames are never saved.

2.2 Purpose

This information is used only to decide, in real time, whether the user is blinking or looking at the screen, so the App can treat that as a switch press and operate the relay. It is not used for advertising, analytics, profiling, identity verification, face recognition, or account creation.

2.3 Storage, retention, and deletion

Face data is kept only in device memory for as long as it is needed to evaluate the current frame. It is discarded when the next frame arrives, when the App moves to the background, or when face tracking stops. It is not written to disk, the photo library, iCloud, a server, or log files. Because face data is not retained, there is no stored face data to delete. Uninstalling the App leaves no face data on the device.

2.4 Sharing and disclosure

Face data is not shared with any third party. It is not sent to an external server, analytics tool, advertising SDK, or cloud service. The only Bluetooth payload sent to the relay board is a one-character command (“1” for on or “0” for off). That command does not include face data.

2.5 Where the information is stored

Face data is processed only in memory on the user’s device. It is not stored on any server or database controlled by the developer or any third party.

3. Other information

3.1 Camera

The front camera is used only so ARKit can detect blinks and gaze. Video is processed on-device and is neither saved nor transmitted. The camera is used only after the user grants permission, which can be withdrawn in iOS Settings at any time.

3.2 Bluetooth

The App connects to a relay board chosen by the user and sends on/off commands. The only values saved are the board identifier used for auto-connect and the user’s own settings. These are stored in UserDefaults on the device and are not face data.

3.3 Network

The App does not use the network. It does not create accounts, collect location data, or track users.

4. Contact

For questions about this policy or our handling of face data, please contact us using the support details listed in App Store Connect.
